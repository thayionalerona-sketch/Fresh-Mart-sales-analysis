
# Power BI Dashboard 📊

This folder contains the Power BI dashboard developed for the FreshMart Sales Analysis project.

## Dashboard Objectives

- Monitor overall sales performance.
- Identify monthly sales trends.
- Compare store performance.
- Analyse customer basket sizes.
- Monitor stockout events.
- Identify opportunities to improve revenue.

## Key Performance Indicators (KPIs)

- Total Sales Revenue
- Total Transactions
- Average Basket Value
- Average Items per Basket
- Store Performance

## Tools

- Microsoft Power BI
- Power Query
- DAX
- Data Visualisation
