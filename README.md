
# FreshMart Sales Analysis 📊

## 1. Project Overview

This project investigates sales performance at FreshMart Supermarkets during 2025.

The aim is to understand why sales are declining and identify opportunities to improve business performance.

## 2. Business Problem

FreshMart is experiencing a decline in sales revenue.

The business needs to understand the factors affecting sales, customer purchasing behaviour and basket sizes.

## 3. Project Objectives

- Analyse sales performance over time.
- Investigate changes in average basket value.
- Identify purchasing patterns.
- Investigate store performance.
- Examine stockout events.
- Provide recommendations to improve sales.

## 4. Dataset Description

The dataset contains information about:

- Customer transactions
- Store information
- Stockout events
- Transaction dates
- Basket values
- Number of items purchased
